# DeskLatch Windows 安装

解压安装包，双击 `install.cmd`。选择安装目录和接入方式，再点「开始安装」。安装所需的下载和缓存会保存在所选目录内。

| 接入方式 | 安装后怎么用 |
| --- | --- |
| DeepSeek Harness 插件 | 先完成 DSH 的首次启动并从托盘退出。安装后重新打开 DSH，可在会话里批准或拒绝关键动作。试用时请 Agent 填写 `Title`，再点击测试表单里的 `Send message`。 |
| MCP | 安装后点击「复制 MCP 配置」，把配置添加到你的客户端。若客户端只接受单条服务器配置，复制 `mcpServers.desklatch` 条目。 |

**本地文字识别**和 **E2B 云电脑**默认跳过。每项可单独选择安装或使用已有配置。选择安装文字识别会准备便携 Python、本地环境和模型。选择安装 E2B 会安装 SDK，密钥可现在填写或之后通过向导补填。E2B 云电脑由实际使用的宿主创建。

需要检查路径和安装包时，可运行 `install.cmd /plan`。它显示默认目录和找到的安装包。`DESKLATCH_INSTALL_ROOT` 可预填向导的安装目录。
