# DeskLatch Windows 安装

解压安装包，双击 `install.cmd`。选择安装目录和接入方式，再点「开始安装」。DeskLatch 的运行时和缓存保存在所选目录。DSH 插件沿用当前 DSH 配置已绑定的 pnpm 仓库，首次安装时在该配置下创建仓库。

| 接入方式 | 安装后怎么用 |
| --- | --- |
| DeepSeek Harness 插件 | 先完成 DSH 的首次启动并从托盘退出。安装后重新打开 DSH，可在会话里批准或拒绝关键动作。 |
| MCP | 安装后点击「复制 MCP 配置」，把配置添加到你的客户端。若客户端只接受单条服务器配置，复制 `mcpServers.desklatch` 条目。关键动作由 DeskLatch 的 Windows 审批窗口确认。 |

基础安装面向 Windows x64，自动安装 CUA 和原生窗口核验依赖。安装后打开想授权的应用，点击「打开授权页」，勾选应用并保存。也可从安装目录双击 `DeskLatch-Authorize.cmd`。按应用管理授权，同一应用中归属可核实的窗口沿用该授权。撤回授权后，该应用的后续动作会停止。

保持目标窗口可见。已获授权的应用可以通过 `observe` 列出，再用 `act` 切换。普通控件操作经本地核验后直接执行。明确会发送、付款、覆盖等动作请求批准。作用不明时，Agent 会收到需要补充证据的结果。前台输入和全桌面截图在授权页分别开启。

使用坐标操作时，在授权页开启前台输入和截图。Windows 预览使用主显示器的截图，自动对齐系统当前显示缩放与点击落点。坐标也会经过目标和风险核验。

开启前台输入后，Agent 明确切换到一个只有最小化窗口的已授权应用时，DeskLatch 会尝试恢复该应用的主窗口。确认窗口已到前台后，工具会重新观察。普通观察不会触发恢复。

卸载 DSH 插件时，从托盘退出 DSH，双击 DeskLatch 安装目录里的 `DeskLatch-Uninstall.cmd` 并确认。卸载脚本从安装记录读取 DSH 配置，通过官方插件命令移除 DeskLatch。

**本地文字识别**和 **E2B 云电脑**默认跳过。每项可单独选择安装或使用已有配置，DSH 与 MCP 都会加载选中的功能。

- **OCR** 安装时会准备 Python 和模型，也可以复用已有 `ocr.json`。在授权页允许截图后，控件证据不足的动作可以由本地 OCR 识别目标区域并补充审批证据。
- **E2B** 可以在向导里填写密钥，也可以复用含 `E2B_API_KEY` 的 `.env`。工作区会列出云端浏览器和 Writer。首次切换到云端应用时才会创建临时云电脑和使用额度。两个云端应用共用这台电脑。[云端浏览范围和使用方式](https://github.com/wszkxlllll/desklatch/blob/codex/independent-runtime/docs/setup-optional.md#e2b)

需要检查路径和安装包时，可运行 `install.cmd /plan`。它显示默认目录和找到的安装包。`DESKLATCH_INSTALL_ROOT` 可预填向导的安装目录。
